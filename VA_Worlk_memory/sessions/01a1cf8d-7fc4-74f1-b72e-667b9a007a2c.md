| 优化方式 | 能减少什么 | 保持效果的条件 |
|---|---|---|
| **恒值曲线精简**，优先推荐 | 将几百个相同关键帧压到首尾两个 | 保留曲线绑定、时间范围和恒定插值。例如恒为 `-1` 的曲线仍然控制镜像，比整条删除更稳妥 |
| **精确移除冗余关键帧** | 删除不改变整段插值形状的中间点 | 必须检查切线和插值；关键帧数值相同并不代表中间没有变化 |
| **按误差阈值减帧** | 减少运动曲线上的密集烘焙关键帧，通常更有潜力 | 属于有损优化，需要检查武器端点、手脚接触、表情、循环和混合 |
| **FBX 导入压缩** | 通过 Unity 的关键帧精简或 Optimal 压缩减少导入数据 | 从低误差开始对比；独立导出的 `.anim` 需要另外处理 |
| **重复资源与重复打包排查** | 减少同一动画副本、跨 Bundle 重复依赖 | 确认内容及使用配置相同后统一引用；主要改善包体，不修改动作曲线 |
| **删除无用轨道** | 移除确定不会使用的骨骼或属性曲线 | 必须核对所有使用它的 Prefab、Avatar 和运行时节点；只在一个模型上找不到节点还不够 |
