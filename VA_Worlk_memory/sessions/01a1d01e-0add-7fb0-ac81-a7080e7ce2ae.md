**如果你主要想参考具体参数，先看 Catlike Coding 第一篇。** 文中水流示例给出的设置包括：

| 参数 | 示例值 | 用途 |
|---|---:|---|
| Tiling | `3` | 纹理重复密度 |
| Speed | `0.5` | 流动动画速度 |
| Flow Strength | `0.1` | UV 扭曲幅度 |
| Flow Offset | `0` | 扭曲阶段偏移；文中也比较了 `-0.5` |
| U / V Jump | `0 / 0` | 此阶段示例不使用周期跳跃，后文再加入以减少重复感 |
| Smoothness | 约 `0.7` | 后续法线水面示例的光滑度 |

这些数值对应教程中的纹理与实现，**不能直接当作所有工程通用的预设**。

另外推荐一个配套工具：[Flowmap Canvas 流向图画布](https://github.com/dolag233/FlowmapCanvas)。支持中文、在 3D 模型上绘制流向、无缝贴图、流速与扭曲实时预览，并可导出 TGA；[下载地址](https://github.com/dolag233/FlowmapCanvas/releases)。

如果用于 **Unity 2022 / URP 14**，优先拆第三项 URP 工程；Catlike Coding 的算法可以移植，但它的 Surface Shader 需要改写为 URP 实现。
