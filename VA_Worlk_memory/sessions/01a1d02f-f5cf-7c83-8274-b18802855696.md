### 2. 新增 `FlowMapBrushRegion.cs`

目标：用原始世界空间网格BVH筛选 + 笔刷包围盒裁切，**裁切后才做UV平铺复制**，解决大三角形高Tiling过度填充。
- 构造缓存positions/normals/UV/三角形submesh/bounds。
- BVH最长轴划分，叶12三角形，构建时Array.Sort。
- 每次Prepare复用List和16元素裁切缓冲，无重复建对象。
- 圆形bounds覆盖from–to胶囊，radius+微小padding。
- 方形/贴图的bounds用to为中心，sqrt(3)*radius涵盖旋转立方体。
- Query AABB，按原始三角形编号排序保持共享UV混合顺序。
- Sutherland–Hodgman按世界AABB六个面裁切，插值position/normal/UV，fan三角化。
- **最新补丁**：裁切前每三角形减去同一个整数UV原点，避免远偏移UV插值精度损失；不是逐顶点frac。
- 裁切后跨tile整体平移三角形，GPU裁切。
- 返回同一 `MarkDynamic()` Mesh，`SetVertices/.../UploadMeshData(false)`。
- 不改source。保留原全网格方法用作回归对照。

## 99. Codex

时间：2026-11-13T08:56:11.691Z

**可以分区域控制，而且你这个 Shader 已经支持。建议优先用同一张 FlowMap 的 B 通道保存速度，工具增加独立的速度绘制功能。**

我核对了当前 [Effect_FlowMap.shader](/D:/work2025U3D/Valkyria/ProjectACGMain/ProjectACG/Client/Assets/Shader/Effect/Effect_FlowMap.shader:563)，其逻辑是：

```text
流向向量 = RG × 2 − 1
局部倍率 = lerp(黑色倍率, 白色倍率, B)
流动向量 *= 局部倍率
```

需要开启材质的“局部流动速度”。你描述的作用范围是正确的：

- 两层流动纹理都会受到影响。
- 法线开启“跟随流动”时受到影响。
- 扭曲开启“跟随 Flow Map”时受到影响；独立 XY 滚动扭曲不受影响。

这里指的是 **`_FlowMap.B`**；独立遮罩 `_MaskMap.B` 用于颜色分区，两者用途不同。

B 实际缩放的是每个循环内的流动位移，因此改变局部移动快慢，同时保持共同的循环周期。这个实现适合速度渐变，可以避免各区域直接用不同时间倍率产生越来越大的相位差。

**现成功能还差什么**

目前工具里的“流向强度”通过改变 **RG 向量长度**，已经能够间接画出快慢。但绘制代码限定了 `ColorMask RG`，所以旋涡、径向、平滑都不会修改 B，也没有独立的速度渐变曲线。见 [绘制 Shader](/D:/work2025U3D/Valkyria/ProjectACGMain/ProjectACG/Client/Assets/Editor/TA_Tools/Scene/FlowMapPainter/FlowMapPainter.shader:18)。

用 B 独立存速度更方便：画好旋涡方向后，可以反复调整快慢，不必重画方向；运行时还复用已有 FlowMap 采样，不需要增加一张速度贴图。

**我建议工具这样扩展：**

| 功能 | 使用方式 |
|---|---|
| 绘制内容选择 | `流向向量 / 速度或遮罩`，与圆形、贴图等笔刷形状分开 |
| 单通道绘制 | 选择 R/G/B/A，支持目标值、增加、减少、平滑，保护其他通道 |
| 速度径向渐变 | 设置中心值、边缘值、过渡曲线，支持内快外慢、内慢外快、环形加速 |
| 旋涡联动 | 可只画方向、只画速度，或同时生成方向与速度 |
| 预览 | 单通道灰度、速度热力图，以及按配置计算的流动预览 |
| 配置预设 | 保存材质贴图属性、通道含义、编码方式、UV 和速度映射 |

例如当前材质设置“黑色倍率 0、白色倍率 2”：

| 目标效果 | 外圈 B | 内圈 B | 对应倍率 |
|---|---:|---:|---|
| 从外到内减速 | 1 | 0.1 | 2 倍 → 0.2 倍 |
| 从外到内加速 | 0.1 | 1 | 0.2 倍 → 2 倍 |
| 中间一圈最快 | 通过曲线设置 | 通过曲线设置 | 中心和边缘慢，中间快 |

建议增加**固定旋涡中心与作用半径**，修改曲线时始终围绕同一个中心。速度曲线和笔刷边缘柔和度要分开，否则重复涂抹会把原本想要的速度渐变刷没。

还要区分“移动快慢”和“转一圈快慢”：同样的移动速度，越靠近中心转一圈越快。可以提供“匀角速度”预设，让移动速度随半径增加，中心设置柔和的小核心区，避免中心方向突变。

**通用性靠可配置的通道规则，不把 B 写死为速度。**

建议提供三种配置：

- **当前 Shader 预设：** RG 流向、B 速度，读取材质黑白倍率，与材质预览一致。
- **普通 RG FlowMap：** 通过调整 RG 向量长度控制速度，适用于保留向量长度的 Shader；如果 Shader 会强制归一化，就不能靠这个方法控制快慢。
- **自定义配置：** 速度可以在同图 A/B，也可以在另一张贴图的任意通道。独立速度图需要目标 Shader 本身支持读取，工具不能仅靠绘制让它自动生效。

## 101. Codex

时间：2026-11-13T08:58:42.370Z

对，**速度图本质上就是单通道的灰度数据**。放在 B 通道只是打包方式；它究竟表示速度、遮罩还是粗糙度，由 Shader 决定。

所以可以把工具扩展成 **“Mesh 贴图绘制工具”**，FlowMap 作为其中一种绘制模式。你这个方向更通用。

建议统一操作流程：

**选 Mesh → 选材质槽 → 选贴图属性 → 选绘制内容 → 直接在模型上画。**

| 绘制内容 | 操作方式 | 典型用途 |
|---|---|---|
| 单通道 R / G / B / A | 绘制 0～1 灰度值，其他通道保持原样 | 速度、透明度、金属度、粗糙度、AO、分区遮罩 |
| RGB 颜色 | 选择颜色绘制，保留 A | 主贴图、颜色分区、发光颜色 |
| RGBA 颜色 | 绘制颜色和目标 Alpha，可分别锁定通道 | 带透明度的颜色贴图 |
| FlowMap 向量 | 保留方向、旋涡、径向、向量平滑 | 流向绘制，可联动指定速度通道 |

这里需要把**材质的贴图槽位**和**贴图内部的 RGBA 通道**分成两项。比如：

```text
材质：水面材质
贴图属性：_FlowMap
绘制内容：单通道
写入通道：B
目标值：0.8
```

换成 `_MaskMap → G` 就能画 G 通道遮罩；换成 `_BaseMap → RGB` 就能直接画颜色。

**笔刷也统一复用，但操作含义要分开：**

- 圆形、方形、笔刷库贴图：作为覆盖形状，所有模式共用。
- 灰度模式：设置数值、增加、减少、平滑、填充。
- 颜色模式：颜色涂抹、颜色平滑、填充。
- FlowMap 模式：方向、旋涡、径向、向量平滑。
- 径向渐变：支持“中心值／颜色 → 边缘值／颜色”，用曲线控制过渡，速度渐变只是其中一种用途。

**笔刷强度与写入数值必须独立。**例如目标 Alpha 为 0.2，笔刷强度为 0.5，表示逐步画向 0.2，不能把透明度和涂抹力度混为一个参数。

有几处实现需要特别处理：

1. **通道保护**：画 B 不改 RG/A，画 RGB 不改 A；清空、平滑、撤销也遵守相同规则。
2. **颜色空间**：颜色绘制遵循目标贴图的 sRGB 设置；数据通道按数值处理。不能把所有贴图都按当前 FlowMap 的线性数据流程导出。
3. **擦除值可配置**：FlowMap 的中性值是 RG=0.5；速度可能恢复为 1 倍，AO 可能恢复为白色，不能统一擦成黑色。
4. **预览一致**：提供材质效果、RGB、单通道灰度、Alpha 和 FlowMap 箭头预览。只有配置了速度映射时，才把灰度标成“几倍速度”。
5. **性能保持局部更新**：普通颜色和通道绘制继续走 GPU，只处理笔刷覆盖区域，不逐笔 CPU 回读；邻域平滑按需开启。

**我建议最终做成“通用绘制核心＋用途预设”。**默认提供“FlowMap”“灰度遮罩”“颜色贴图”三类；当前 Shader 的“RG 流向＋B 速度”作为现成预设。这样日常使用直观，也能适配其他 Shader，而不用每增加一种遮罩就再写一个工具。
