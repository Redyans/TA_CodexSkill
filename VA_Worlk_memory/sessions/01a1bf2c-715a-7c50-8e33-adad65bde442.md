## 7. Codex

时间：2026-11-09T08:19:17.188Z

**当前版本的 `Chara_Cloth_V2`，这个 Alpha Test 没有真正生效。** 你截图里勾选开关、把 Clip 调到 `0.39`，不会触发透明裁剪。

查到的原因是：Shader 声明了开关、`_ALPHATEST_ON` 关键字和 `_Clip` 参数，但主渲染里**没有根据贴图 Alpha 执行 `clip()` 裁剪**，见 [Chara_Cloth_V2.shader:607](/D:/work2025U3D/Valkyria/ProjectACGMain2/ProjectACG/Client/Assets/Shader/Character/Chara_V2/Chara_Cloth_V2.shader:607)。

正常补齐功能后，应这样使用：

1. 在**基础贴图的 A 通道**绘制遮罩：白色保留、黑色挖空。
2. Unity 贴图导入设置中，确保 **Alpha Source = Input Texture Alpha**。
3. 勾选 **Alpha Test**，调整 **Clip**。例如 `0.39` 表示 A 值小于 `0.39` 的像素被裁掉；阈值越高，裁掉的区域通常越大。这是镂空效果，不是半透明。

另外，这个 Shader 的 A 通道还用于「**BaseTex.a区域启用漫反射混合**」，补裁剪时需要考虑通道复用，并同步处理深度、描边等 Pass，避免镂空后残留遮挡。

本次仅核对源码，未修改文件、未做 Unity 实渲验证。
