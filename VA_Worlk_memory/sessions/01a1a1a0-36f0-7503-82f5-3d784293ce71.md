### 1. `catalogOnly` 状态在 Unity Play Mode 域重载后丢失

`BatchCatalogValidate()` 设置：

```csharp
catalogOnly = true;
SessionState.SetBool(Pending, true);
```

但是进入 Play 会域重载，静态字段重置，静态构造函数目前只做：

```csharp
if (SessionState.GetBool(Pending, false)) Register();
```

没有恢复 `catalogOnly`。

结果：
- `catalog-validation.txt` 没有生成
- batch 进入 Play 后执行了普通流程/清理
- 需要用 `SessionState` 保存并恢复 catalog 模式

应修改：

```csharp
private const string CatalogPending = Pending + ".catalog";
```

静态构造：

```csharp
if (SessionState.GetBool(Pending, false))
{
    catalogOnly = SessionState.GetBool(CatalogPending, false);
    Register();
}
```

`BatchValidate()`：

```csharp
SessionState.SetBool(CatalogPending, false);
```

`BatchCatalogValidate()`：

```csharp
SessionState.SetBool(CatalogPending, true);
```

`Finish()` 和 `FinishCatalog()`：

```csharp
SessionState.SetBool(CatalogPending, false);
catalogOnly = false;
```

### 2. 动态皮肤销毁时出现 Unity Assertion

日志中出现多次：

```text
Assertion failed on expression: 'go.IsActive()'
UnityEngine.GameObject:Find(String)
MonoSingleton`1:get_Instance()
D11.Skin.SkinSystem:_InnerAbandonSkin
D11.Skin.SkinSystem:HideSkin
AlphaAceOfflineSkin:OnDisable
```

原因：
- 动态武器销毁或禁用时，`AlphaAceOfflineSkin.OnDisable()` 调用：
  ```csharp
  SkinSystem.Instance.HideSkin(handle)
  ```
- 对象已经 inactive，SkinSystem singleton 查找触发 Unity assertion

建议修改：

`Assets/Scripts/Recovery/AlphaAceOfflineSkin.cs`

新增缓存：

```csharp
[NonSerialized] private SkinSystem skinSystem;
```

OnEnable 初始化后：

```csharp
SkinSystem.Init();
skinSystem = SkinSystem.Instance;
```

新增：

```csharp
public void ReleaseSkin()
{
#if UNITY_EDITOR
    try
    {
        if (handle != null && skinSystem)
            skinSystem.HideSkin(handle);
    }
    finally
    {
        handle = null;
        if (originalMaterials != null)
        {
            foreach (var pair in originalMaterials)
                if (pair.Key) pair.Key.sharedMaterials = pair.Value;
            originalMaterials = null;
        }
        if (ownsDebugState) SkinSystem.DebugState = previousDebugState;
        ownsDebugState = false;
        skinSystem = null;
    }
#endif
}
```
