## 14. Codex

时间：2026-11-11T01:28:55.481Z

**直接给 Image 换材质做模糊，确实可以只用 Shader。** 我上一版按“完整算法＋缓存优化”实现，所以加了脚本，没有提前把这个区别说清楚。

三种算法的情况不同：

- **Grainy Blur**：单个 Shader 就能完成。
- **Kawase Blur**：单次滤波可以只用 Shader；多轮迭代需要脚本调度。
- **Dual Blur**：完整算法需要连续降采样、升采样和多个中间 RT。Unity 的 Image 不会自动执行这套流程，即使 Shader 写了多个 Pass，也需要脚本或 RenderFeature 调度。

上一版脚本负责准备 RT、调度这些 Pass、缓存静态图片结果，以及自动处理图集 UV；模糊计算仍在 GPU Shader 中完成。

**你期待的“只挂材质、直接调参数”可以做。** 但纯 Shader 版本里的 Dual Blur 只能做近似效果，无法保留真正多级 Dual Blur 的实现和性能优势。

## 16. Codex

时间：2026-11-11T01:31:02.305Z

**大面积、较强模糊优先用 Dual Blur；小图标轻度模糊优先用 Kawase。** 具体要在相近视觉效果下比较。

| 算法 | 性能特点 | 推荐场景 |
|---|---|---|
| **Dual Blur** | 多轮处理，但逐级缩小 RT，大范围模糊通常最划算 | 场景 RT、全屏背景 |
| **Kawase Blur** | 每轮 4 次采样，少量迭代成本低 | 小图标、轻度模糊 |
| **Grainy Blur** | 当前版本每像素 8／16／32 次采样；低档颗粒明显 | 刻意需要颗粒质感 |

按你的两种用途建议：

- **场景 RT → UI**：Dual Blur，先用 **Half 分辨率、3–4 级**。
