Unity 的材质槽对应 Mesh 的 SubMesh：图2把 BaseLit 放到 Element 1，不会自动覆盖 Element 0 的头发几何；它只会用于对应的另一个 SubMesh（如果有）。原 Hair 材质因此仍会绘制，所以红色保留。图1只有 BaseLit，原材质已经不参与绘制，自然不会再画出红色。

Timeline 的“追加绘制”又是另一种实现：它创建临时 Renderer，拿同一 Mesh 只绘制选中的 SubMesh，同时保留原 Renderer。[实现代码](D:/work2025U3D/Valkyria/ProjectACGMain/ProjectACG/Client/Assets/GameScripts/AOT/GameArt/TimelineTrack/CharacterMaterialSwapTrack.cs:575) 因此它不会像图1那样移除原材质。Hair Shader 还包含项目专用的 `Fringe` Pass，项目 Renderer Feature 会单独绘制这个 Pass；叠加 BaseLit 不会关闭它，原来的红色发片仍可能再次出现。[Hair Pass](D:/work2025U3D/Valkyria/ProjectACGMain/ProjectACG/Client/Assets/Shader/Character/Chara_V2/Chara_Hair_V2.shader:298) [Feature 配置](D:/work2025U3D/Valkyria/ProjectACGMain/ProjectACG/Client/Assets/AssetRaw/Settings/URP-Battle-High-Renderer.asset:491)
