是的，Dual Kawase Blur 对大半径模糊会明显好于当前方案，但关键不是“单个 Shader 文件”，而是“多 Pass + 多次执行”。

- 采样覆盖稀疏，所以容易出现菱形、断层和边缘拉伸

Dual Kawase 的流程是：

1. Downsample 降采样
2. 多次低分辨率模糊
3. Upsample 逐级放大
4. 最后显示结果

这样半径扩大时，采样频率降低但覆盖范围增加，效果更连续，性能也比全分辨率堆很多采样更好。

- **Dual Kawase 多 Pass：效果和性能都更适合大模糊**

## 44. Codex

时间：2026-11-16T07:27:40.199Z

有，但要区分“看起来范围大”和“真正高质量大范围模糊”。

最适合单 Pass 的方式是使用纹理 Mipmap：

- 直接用 `SAMPLE_TEXTURE2D_LOD` 采样更高 Mip
- Mip 越高，模糊范围越大
- 只需要 1 次或少量采样，性能很好
- 适合静态 UI 图片、预先生成 Mipmap 的 RenderTexture

但它有明显限制：

- UI Sprite 和图集通常没有合适的 Mipmap
- Atlas 的 Mipmap 会混入相邻 Sprite
- Alpha 边缘可能产生黑边、串图和颜色污染
- 模糊半径不是连续精确控制，而是近似选择 Mip 层级

第二种是单 Pass 多采样：

- 16、24、32 个加权采样点
- 使用双线性采样合并采样点，降低实际纹理读取次数
- 比当前 4/8/12 点效果好
- 但半径越大，采样越稀疏，性能和画质会同时下降

如果是动态屏幕背景或动态 RenderTexture，单 Pass 没有可靠的大范围方案。因为 Shader 只能读取输入纹理，不能在同一个 Pass 内生成降采样纹理、建立 Mipmap 或反复执行模糊。

结论：

- **静态图片**：可以做“单 Pass + Mipmap/预模糊纹理”，这是最现实的无脚本方案。
- **普通 Sprite 图集**：不建议直接用 Mipmap，大半径容易串图。
- **动态画面、弹窗背景、可调大半径**：必须使用多 Pass Dual Kawase、RenderTexture 或预处理链。
- **完全无脚本且要求大范围高质量**：做不到稳定兼顾画质和性能。当前单 Pass 只能改成 16/24 点采样改善中等半径，不能根治大半径问题。
