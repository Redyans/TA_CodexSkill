## 10. Codex

时间：2026-11-10T09:27:43.386Z

我把 **RGB 颜色混合与 Alpha 混合分开了**，修改在 [Chara_EyeBlend_V2.shader:90](/D:/work2025U3D/Valkyria/ProjectACGMain/ProjectACG/Client/Assets/Shader/Character/Chara_V2/Chara_EyeBlend_V2.shader:90)。

原来：
```shaderlab
Blend [_SrcBlend] [_DstBlend]
```
颜色和 Alpha 共用材质设置。腮红采用 `SrcAlpha / OneMinusSrcAlpha` 时，假设腮红 Alpha 为 **0.5**，底下脸部 Alpha 为 **1**：

```text
输出 Alpha = 0.5 × 0.5 + 1 × (1 − 0.5)
           = 0.75
```

因此，脸部这块区域在 RT 中变成了半透明，后续合成时就会透背景。

现在：
```shaderlab
Blend [_SrcBlend] [_DstBlend], One OneMinusSrcAlpha
```
逗号前控制 RGB，继续使用材质原来的混合方式；逗号后单独控制 Alpha：

```text
输出 Alpha = 0.5 × 1 + 1 × (1 − 0.5)
           = 1
```

这样腮红仍以 **0.5 的透明度叠加颜色**，脸部整体保持不透明。这个公式也保留了正确的透明覆盖率：如果底下是 Alpha 为 0 的空背景，输出 Alpha 就是 0.5，并没有强制所有像素都变成 1。
