# 3ds Max 批量骨骼动画传递与关键帧持久化参考｜2026-11-16

> 类型：REFERENCE；适用范围：在多个 3ds Max 场景间批量传递选定骨骼的动画，并确认保存后的活动控制器仍可播放；使用前提：重新核对目标 Max 版本、Rig、Controller/Animation Layer、时间范围和最终消费者。
> 关联既有规则：`DCC-DOC-01`、`DCC-CMP-01`、`DCC-BKE-01`、`DCC-REV-01`、`DCC-OPS-01`、`DCC-VAL-01`；项目专属事实见 [未分类 3ds Max Profile](../../../Profiles/CodexDaily/Unclassified_2026-11-16.md) 与 [DCC 模块入口](../../README_Tech_DCCDevelopmentRules.md)。

## 1. 适用场景

- 需要按文件配对规则批量从 A 组 `.max` 场景向 B 组场景传递骨骼动画。
- 只允许处理参考 Selection Set 中的白名单骨骼，且 A/B Rig 可能存在缺失、重名或父级差异。
- 日志显示节点已处理或已写键，但保存后时间轴没有关键帧、活动层不可见或动画不播放。

## 2. 前提与依赖

- 明确 Max 和插件版本、A/B 文件配对规则、骨骼唯一名称、父级/Controller 兼容条件、A 的动画范围与采样步长，以及 B 文件是否允许覆盖。
- 确认关键帧要写入的 Controller/Animation Layer 和最终消费者；不要只凭节点名、UI 截图或 `numKeys` 推断活动动画。
- 先准备未被旧批处理覆盖的 B 副本、可恢复的备份和带阶段信息的日志。批处理写入前应验证完整目标集合。
- 若原始实现是加密或编译的 `.mse`，它不能作为可检查的 MaxScript 源码；新写 `.ms` 只能依据已观察到的需求独立实现，不能声称与原工具内部算法等价。

## 3. 实现或排查步骤

1. 按显式配对键建立 A/B 文件映射；先报告缺失、重名、重复和不兼容目标，再执行写入。若用参考场景 Selection Set 作骨骼白名单，只读取并缓存一次，避免不同输入文件改变处理集合。
2. 每个 A 文件分别读取动画起止帧和采样步长。先完整采样到内存，再改写 B，避免写入目标反过来影响后续求值。
3. 将帧范围与关键时间单位分开管理：动画区间使用帧语义，写键时传入目标 Max 接受的时间值；若使用 ticks，按当前宿主 API 正确转换，不要把 ticks 整数再次当作帧传入。
4. 映射到 B 的目标节点后，记录实际 Controller 类型、父级和活动层。若要保留 B 的基础姿势，应按确认的变换合同传递相对变化；直接覆盖为 A 的绝对姿势可能破坏 B 的原始姿势。
5. 对目标 Controller 写键后，区分“节点匹配”“写键调用完成”“文件保存成功”三个阶段。`addNewKey` 返回或 `.value` 赋值成功，不足以证明活动轨道上出现可播放关键帧。
6. 保存 B 后关闭并重新打开干净副本，检查实际活动 Controller/Layer、关键帧首末时间、位置/旋转/缩放数据和时间轴显示，再实际播放代表帧。

## 4. 风险与不适用边界

- Max Controller、复合 Controller 和 Animation Layer 的行为受版本及插件影响。`numKeys = -1` 表示该 Controller 不能直接计数时，不应等同于零键；零、负值和计数异常必须分别记录。具体版本差异见 Profile。
- 加载场景可能清理或替换某些 Animation Layer Controller；日志统计到的键数不一定是保存后活动层的键数。
- 只看“处理成功”、写入数量、静态括号检查、文件保存或节点匹配，不足以证明动画能在目标场景播放。
- 直接覆盖 B 有破坏性；测试必须使用副本。缺少稳定 Controller 映射、单位/父级变化或最终消费者时，不应自动写入。

## 5. 验证与回退

- 日志分别报告配对数、匹配/跳过骨骼、Controller 类型、写入键数、保存结果、重载结果和播放检查；不能以一个“成功”标记覆盖这些阶段。
- 在目标 Max 中保存并重载后，确认活动 Controller/Layer 与首末帧；再比较代表帧的 Position、Rotation、Scale、B 基础姿势和实际播放。
- 若键数为零、控制器不支持计数、重载失败或结果不播放，阻断后续覆盖并保留原 B；从未被本轮或旧版写入的备份恢复，再定位 Controller/Layer。
- 回退时恢复原始 B 文件与配置；修正时间单位、映射或控制器写入后，从干净副本重跑完整保存/重载/播放链。
