# ProjectACG Mesh 贴图绘制工具 Profile｜2026-11-13

> 类型：PROFILE；项目：ProjectACG；记录会话报告的工具能力、问题与验证状态；硬件和测试工程数据仅适用于其注明条件。

## 1. 项目事实与现象

工具目录：`Client/Assets/Editor/TA_Tools/Scene/FlowMapPainter/`。当日旧入口为 `TA_Tools/Scene/FlowMap绘制工具`；会话后来报告新增通用入口 `TA_Tools/Scene/Mesh贴图绘制工具`，旧入口保留。

### 能力与交互

- 工具扩展到单通道 R/G/B/A、RGB、RGBA，通道锁定、颜色/目标值绘制、平滑、擦除/填充、渐变和环形渐变、FlowMap 向量与速度联动、UV0～UV3、通道预览、自定义预设及工作状态恢复。
- 后续 UI 将内容与 UV 合并，将低频映射/擦除/整图/预设等折叠；模型与贴图、绘制与笔刷、预览、文件与整图操作分区。旧工作区中展开的笔刷库/预览/帮助面板在首次加载新版布局时收起，底部主要开始绘制入口保留。
- 单通道模式只写所选通道；RGB 按锁定设置写颜色并保留 Alpha；RGBA 才写 Alpha。旧工作状态中的“增加/减少”按直接目标值绘制兼容处理。
- 先前扩展包括旋涡、径向和平滑笔刷、数位板压感、状态恢复；数位板手感未在真实设备确认。

### UV 与绘制范围

最初选中 Sphere 后无笔刷，报告根因是 UV 检查将 Unity Sphere 的轻微负值（约 `-0.000921`）误判为无效。后续按用户要求取消 `[0,1]` 范围拦截；会话报告负值、多区块、远离原点和接缝可绘制，并正确应用材质 Tiling/Offset。Repeat 模式下跨区会写到同一周期纹理；仍要求 Mesh 有所选 UV 通道。

### 性能与修复

初始报告指出每次抬笔会同步读回整张图、编码 PNG 并写盘；高倍平铺时每个落点提交整个网格。工具后续报告实现异步恢复备份、静态预览停止定时重绘、按需播放预览、合并连续刷新、局部三角形提交和大三角形裁切。一次优化发现 CPU 裁切拖慢高面数普通 UV 模型，后改为缓存小三角形并只更新笔刷范围索引、大三角形才裁切。

工作区恢复曾导致“一键配置并开始绘制”立刻暂停。会话调查看到普通 `[Serializable]` 内联绑定空引用在窗口状态 JSON 恢复后成为空对象；程序把非空对象当作已有绑定，然后 `Matches()` 失败，`Tick()` 将其判为材质变化。会话报告修复了空绑定判定，并使重复一键配置复用现有材质/画布，保留笔迹；真正改变材质/贴图/UV 时仍应暂停保护。

## 3. 根因与修正边界

- 笔刷未出现：微小 UV 边界负值触发过严的 `[0,1]` 拒绝；取消范围限制而保留 UV 通道存在性与纹理映射检查。
- 抬笔卡顿：同步全图 readback/编码/写盘；工具报告改为异步恢复快照写入。用户显式导出 PNG 仍为同步保存。
- 高倍平铺卡顿：每次全网格提交；改局部三角形索引，但 CPU 筛选有成本，普通模型性能需分别量测。
- 一键设置后停止绘制：已配置状态中的空内联绑定被序列化恢复为默认对象；修正“未捕获绑定”和“捕获后引用失效”的区分，避免丢失材质变化保护。
- 窗口主按钮不可用：配置已完成但旧状态逻辑仍显示待配置/禁用入口；会话报告改成按已有材质与一键新建模式提供有效的底部主操作。

## 4. 未验证项、规则候选与回退

- 真实模型/生产 Editor 的笔刷手感、真实数位板压感、复杂重复/重叠 UV、Undo 长时间内存占用，以及不同 GPU/图形 API 尚未完成用户侧验收。
- 会话结束仍有 FlowMap Shader 远近尺寸问题待澄清：模型预览 UV 不按距离缩放，用户可能指笔刷大小或贴图细节；当天只讨论 Screen UV/视距补偿取舍，没有改 FlowMap Shader 或绘制笔刷尺寸。
- 低分辨率/普通 UV 情况下局部三角形筛选可能增加少量 CPU 开销；异步流程关闭窗口/域重载的完整写入保障只按会话结果记录，未独立复测。
- UV 校验、序列化空绑定判定和性能门槛都依赖当前工具实现，保留为 Project Profile 事实。它们可参考对应通用流程，但本次证据不足以作为正式 CORE 候选升级。
- 出现像素/恢复问题时可保留源贴图并退回旧 FlowMap 入口/旧工作区值；恢复不包含撤销历史（会话明确说明）。
