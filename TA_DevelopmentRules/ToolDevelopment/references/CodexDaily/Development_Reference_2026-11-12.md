# Editor 资产生成与绘制工具参考｜2026-11-12

> 类型：REFERENCE；适用范围：Unity Editor 的 Prefab/Timeline 生成器、资产清理和 Scene 绘制工具；使用前提：按目标版本、资产所有权和引用范围重新验证。
> 关联既有规则：`TOOL-CMP-01`、`TOOL-OPS-02`、`TOOL-VAL-02`、`TOOL-VAL-03`；ProjectACG 案例见 [工具问题与 FlowMap Painter Profile](../../Profiles/ProjectACG/CodexDaily/Development_Profile_2026-11-12.md)。

## 1. 适用场景

- 从 FBX/Mesh 重新生成 Prefab，处理源层级改名、删除、旧组件数据和外置 Mesh 清理。
- 保存 Timeline/Prefab 时遇到序列化绑定指向已不存在的 Track。
- Scene 视图直接在 Mesh 上绘制贴图，需同时控制交互反馈、GPU 写入、恢复备份和资源保存。
- Editor 源码已改但用户仍观察到旧行为，或测试资源被现有 Unity 实例占用。

## 2. 前提与依赖

- 区分 Prefab GameObject、FBX 源 Mesh、拆出的 `.mesh` 资产和所有引用者；一个对象从某个 Prefab 消失，不代表 Mesh 文件已成为孤儿。
- 生成器的保护快照、源状态标记、外部引用扫描与清理策略要有清楚的所有权合同。删除旧节点的授权不能扩大到快照中的其他节点。
- 源码时间较新不代表 Unity Editor 正在运行新程序集。编译产物/域重载状态需与源码变更时间核对。
- Scene 绘制工具需定义 UV 范围、重叠 UV、SkinnedMesh 姿态、贴图通道/属性、临时预览生命周期、Undo、备份格式和磁盘写入路径。

## 3. 实现或排查步骤

1. **核实生成版本**：检查目标源码与 Editor 程序集是否都包含本次逻辑，确认 Unity 已完成脚本重编译和域重载；单独的 `dotnet build` 只能说明工程可编译，不能证明用户当前 Editor 已加载新逻辑。
2. **区分层级与资产**：将源层级、新旧 Prefab GameObject、外置 Mesh GUID 和所有引用分别列出；改名通常表现为旧节点移除、新节点创建，清理资产前先扫描所有 Prefab/Scene 消费者。
3. **给过期节点做显式删除登记**：只豁免用户/源状态允许清理的节点子树；保护校验继续覆盖其他节点、组件与引用。改名、删除、手工子节点及 ShadowProxy 等变体都要有回归用例。
4. **对失效绑定按目标身份清理**：只删除已能证明目标 Track 不存在的记录，保留有效绑定、合法空目标及外部引用；向用户报告处理数。重复保存需幂等，不能只吞异常而把坏记录留在资源中。
5. **检查可见名称不一致**：对严格匹配失败的 FBX 名称查看 Unicode 码点并统一生成/校验两侧的规范化合同。视觉上相同的字符串仍可能含 `U+200B` 等不可见字符；不要仅靠 UI 目测排除。
6. **设计 Scene 绘制闭环**：交互时尽量让 GPU 更新只处理笔刷覆盖区域；把 PNG 编码/恢复备份与鼠标抬笔的同步路径区分测量。大贴图的备份若同步读取 GPU 并编码，可能造成明显卡顿。
7. **隔离验证**：在不占用用户工程的 Unity 测试工程验证编译、GPU 绘制、Undo/Redo 和资源导入；再由用户验证真实场景 UI、模型 UV 和生产工程状态。不要把独立 GPU 测试写成主工程交互通过。

## 4. 风险与不适用边界

- 旧 `.mesh` 仍被场景或低配/战斗 Prefab 引用时，默认删除会造成 Missing 引用；即使用户要求强制删除，也要明确受影响资源和不可自动迁移的边界。
- 授权删除快照中的一棵子树，不应关闭其他结构保护检查。
- 高分辨率 GPU 读回和 PNG 压缩可能在操作结束时阻塞主线程；单次平均绘制更新耗时不能代表抬笔/保存尖峰。
- `U+200B` 的个案提示输入规范化问题，不证明所有 Unicode 名称都应无条件剥除格式字符；改名规则可能影响合法资产名。
- 用户工程已打开时，不要为跑批处理 EditMode 测试重复启动另一个 Unity 实例；先用隔离工程或明确的测试策略。

## 5. 验证与回退

逐项验证旧节点改名/删除、手工子节点保留、外部 Mesh 引用、无效 Timeline 键删除、有效键保留与重复保存；检查 GUID、缺失脚本/引用和结果日志。绘制工具记录交互更新、抬笔备份、保存编码和 Undo 成本，并用多分辨率测试。出现资源丢失时优先恢复原资产/引用快照；绘制性能异常时先关闭自动备份或降分辨率，不能以吞掉写入错误作为回退。
