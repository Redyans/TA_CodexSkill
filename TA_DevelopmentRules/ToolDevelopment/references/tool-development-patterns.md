# TA 工具实现模式参考

本文件用于选择最小实现模式，不替代 [../README_Tech_TAToolDevelopmentRules.md](../README_Tech_TAToolDevelopmentRules.md) 的 CORE 或当前项目 Profile。先选择模式，再读取目标附近实际工具；不要因为模板完整就强制采用多文件、全局 Hook 或运行时组件。

## 1. 简单查询 / 单资产辅助

适用：检查当前 Selection、定位资源、读取配置、一次性修复一个明确对象。

- 可使用单一 Editor C# 文件，但仍需命名空间、唯一菜单、输入校验和可定位结果。
- 输入从 ObjectField、Selection 或明确 ContextMenu 获得；无目标、错误类型和资产路径异常必须可见。
- 默认只读。若写入，必须声明写入字段、Undo 与保存边界。
- 不创建全局缓存、导入 Hook、构建回调或运行时依赖。

## 2. 配置型 EditorWindow

适用：参数较多、需要预览/校验/执行、可重复使用的美术或 TA 工作流。

- 入口负责窗口生命周期、状态和调用协调；UI、校验、执行与资产 IO 按复杂度拆分。
- UI 与执行分离：OnGUI 只处理交互和展示，不在 Layout/Repaint 中执行批量写入。
- 配置使用可序列化对象或明确设置资产；默认值与旧配置兼容，提供安全的恢复默认路径。
- 对长耗时工作显示校验、进度、取消条件、耗时和汇总。

## 3. 只读扫描 / 审计报告

适用：缺失资源检测、命名规范检查、材质/Shader 引用审计、资产统计。

- 扫描范围、筛选条件和排除规则必须可见；结果保留资产路径和可点击/可选择定位能力。
- 结果区分未扫描、无问题、告警、错误和扫描失败；空结果不能与“扫描未执行”混淆。
- 默认不自动修复。需要修复时拆成显式的预览与执行阶段，并记录每项结果。
- 大范围扫描不得放在 Editor 每帧、OnGUI 或导入回调中反复运行。

## 4. 批量转换 / 生成 / 迁移

适用：批量生成 Prefab、Mesh、贴图、材质、配置资产，或改写已有资源。

1. 收集候选并解析输入。
2. 校验依赖、输出位置、重名、覆盖、只读和不可处理项。
3. 显示执行计划、影响数量和破坏性风险。
4. 在用户确认后执行，逐项记录成功、失败、跳过与输出。
5. 汇总、定位输出、记录回滚方式。

仅在资源处理能保持一致性时使用批量编辑 API，并保证异常通过 finally 清理。若取消不能保持资产一致性，UI 必须在执行前写明不可安全中断，不要提供虚假的取消按钮。

## 5. Preview / Inspector / Scene GUI

适用：缩略图、模型预览、材质预览、Scene Handle、Inspector 扩展、编辑器临时效果。

- 预览状态与正式资产状态分开。临时材质、RenderTexture、事件和缓存定义释放点。
- 选择变化、窗口关闭、Domain Reload、Play Mode、资源删除和异常时可安全恢复。
- 预览通常不写 sharedMaterial 或全局 Shader 状态；需要保存时必须使用显式“应用/保存”动作。
- 自定义 Inspector 仅负责其目标对象，不能隐式接管无关对象的 Inspector 或 Project 窗口。

## 6. 导入 / 构建 / 运行时协作

适用：资产导入后处理、构建前后检查、Editor 与 Runtime 共用数据。

这是高影响模式，必须先评估能否改为显式菜单、手动刷新或局部配置。只有确实需要自动触发、且幂等性和影响范围可验证时才接入：

- 导入 Hook：限定资产类型与路径，避免每次导入全项目扫描或写回；保护递归导入。
- 构建回调：显式声明影响平台、执行顺序、失败策略和 CI/BatchMode 行为。
- Runtime 协作：将 Runtime API 与 Editor 工具分程序集，禁止 Editor API 泄漏到 Player。
- 全局事件：有订阅与释放、禁用开关、异常隔离与 Domain Reload 处理。

## 7. Shader / 材质工具

适用：Shader 参数驱动、变体收集/裁剪、材质批处理、RenderFeature 配置、烘焙数据生成。

工具层只负责受控地读取或写入 Shader 公开接口；材质属性名、Keyword、Pass、全局资源和变体属于渲染兼容性契约。必须同时遵守 Shader 开发模块：

- 先确认 Properties、CustomEditor / Drawer、脚本写入、动画/Timeline、材质变体和实际消费者。
- 预览与批量写入后，Unity 必须重新导入/编译 Shader，并用目标材质和场景验证。
- 不以 Shader.SetGlobal、sharedMaterial 改写或隐藏 Inspector 字段替代真正的局部材质/运行时隔离方案。
