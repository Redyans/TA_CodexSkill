# Editor 笔刷与顶点色绘制工具 UI 参考

> 类型：REFERENCE；适用范围：Unity Editor 内基于 SceneView 的网格笔刷绘制与顶点色/遮罩绘制窗口；使用前提：必须以目标工程的可写 Mesh 判定、预览材质与 Shader、通道约定和实际素材重新验证。
>
> 关联规则：`TOOL-UI-01`、`TOOL-UI-02`、`TOOL-ARC-02`、`TOOL-CMP-01`、`TOOL-VAL-02`。项目实例见 [ProjectACG 网格地形与地表工具集 Profile](../Profiles/ProjectACG/mesh-surface-terrain-toolset.md)。

## 1. 适用场景

- 在 SceneView 里对网格做顶点色或顶点数据绘制；
- 需要按通道绘制（RGB 合成或单通道 R/G/B/A）并单独查看通道；
- 需要选择「另存为新 Mesh」或「覆盖源 Mesh」；
- 需要笔刷大小、衰减、不透明度的可视化。

不适用于：2D 贴图笔刷、Terrain 层笔刷、必须在运行时绘制的工具。

## 2. 前提与依赖

- 可写 Mesh 判定：直接用导入模型的 Mesh 子资源通常不可写回；覆盖前必须判定目标 Mesh 是否可编辑，不可编辑时只允许另存。
- 预览材质：必须有专用隐藏材质与 Shader；不要把预览状态写进用户的正式材质。
- 通道语义：顶点色通道的含义由项目 Shader 约定决定（例如 A 通道用于描边遮罩），属于项目事实，需要在 Profile 固化，不能凭工具推断。

## 3. 实现或排查步骤

### 3.1 笔刷缩略图用 `StretchToFill` 铺满

- 症状：笔刷缩略图「没有占满」、四周留白，或按比例内接后看起来偏小。
- 根因：IMGUI 用 `ScaleMode.ScaleToFit` 绘制时按比例内接，rect 与贴图比例不一致就会留白。
- 做法：`GUI.DrawTexture(rect, texture, ScaleMode.StretchToFill, true)`；rect 由固定尺寸常量推导，并让布局阶段与绘制阶段使用同一尺寸（`BrushPreviewSize` 常量 + `GUILayout.Width`/`GUILayoutUtility.GetRect`）。
- 边界：同一窗口中另有「按比例缩放」的预览（例如材质球或整图缩略）时保持 `ScaleMode.ScaleToFit`，不要把两处统一改。

### 3.2 「显示通道」与「绘制通道」是两个独立开关

- 绘制通道决定写入哪些通道：RGB 合成写入颜色，单通道写入标量值；
- 显示通道决定预览时只看哪个通道，用于检查单通道结果。

两者的实现约定：

1. 各自一个 `Popup`，标签集合一致（例如 `{"RGB","R","G","B","A"}`）；
2. 默认值按工具语义分别选择（实测：绘制默认单通道、显示默认 RGB）；
3. 单通道显示通过预览材质的 float 属性驱动（例如 `_VertexColorPainterPreviewMode` 取 0~4），由 Shader 按区间分支；不要在 C# 里逐顶点烘焙预览网格；
4. 切换后立即刷新预览材质属性，不依赖下一次绘制。

### 3.3 保存方式：另存新 Mesh 优先，覆盖源 Mesh 需要门槛

- 用枚举 + 标签数组暴露两种方式（例如 `{"另存为新 Mesh","覆盖源 Mesh"}`）；
- 新资产用固定后缀（例如 `_VertexColor`）与源 Mesh 同目录生成，避免让用户手填路径；
- 覆盖必须前置校验：目标可写、顶点数一致；写入前 `Undo.RecordObject(mesh, "覆盖顶点色")`，失败时给出可读原因（例如「覆盖失败：顶点数量不匹配」）；
- 判定不可编辑的目标应在 UI 中禁用覆盖并说明原因，而不是执行后再报错。

### 3.4 预览生命周期

- 预览对象与预览材质按会话创建、按会话释放；选择变化、窗口关闭、异常与 Domain Reload 都要能恢复；
- 预览不写正式材质、不写场景；
- 预览网格缓存用显式版本号或脏标记失效，不要在 `OnGUI` 每帧重建。

### 3.5 笔刷大小与预览圈同源

SceneView 预览圈（`Handles`）与命中测试必须使用同一个笔刷半径换算，避免「看到的圈」与「实际影响范围」不一致；笔刷半径、衰减曲线与不透明度应能从窗口直接读取，不要把换算复制到多处。

## 4. 风险与不适用边界

| 现象 | 常见根因 | 建议处理 |
| --- | --- | --- |
| 缩略图不占满 | 使用了 `ScaleMode.ScaleToFit`。 | 改为 `StretchToFill` 并固定 rect 尺寸。 |
| 切换通道没有效果 | 只改了绘制通道，没有刷新预览材质属性。 | 切换后立即应用显示模式。 |
| 覆盖后其他对象也变了 | 覆盖的是被多处共享的 Mesh 资产。 | 覆盖前确认引用面；或改用另存。 |
| 覆盖报错或中断 | 顶点数不一致，或目标 Mesh 不可写。 | 前置校验并用 `Undo` 记录写入。 |
| 顶点色看不到 | 项目 Shader 未消费对应通道。 | 属于 Shader 模块问题，先确认通道约定。 |
| 缩略图发虚或错位 | 预览贴图尺寸与 rect 不匹配、Alpha/Filter 设置不同。 | 使用固定尺寸并与布局一致。 |

## 5. 验证与回退

| 层级 | 检查 | 通过条件 |
| --- | --- | --- |
| 目标判定 | 可写 Mesh 与不可写（导入子资源）两类。 | 覆盖仅对可写目标开放，其余只允许另存。 |
| 通道 | RGB 与 R/G/B/A 分别绘制、分别显示。 | 单通道绘制不污染其他通道；显示与 Shader 消费一致。 |
| 保存 | 另存与覆盖各执行一次。 | 另存产生新资产且源 Mesh 不变；覆盖后源资产变化且可用 Undo 回退。 |
| 生命周期 | 重开窗口、切换选择、Domain Reload。 | 无残留预览对象、预览材质或全局状态。 |
| 回退 | 保存方式与备份策略。 | 另存天然可回退；覆盖依赖 Undo 与版本控制，交付时必须说明。 |
