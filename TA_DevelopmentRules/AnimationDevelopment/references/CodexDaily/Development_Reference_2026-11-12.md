# 动画曲线压缩与保真参考｜2026-11-12

> 类型：REFERENCE；适用范围：Unity `AnimationClip` 曲线数值精简和资源体积优化；使用前提：针对所有消费者、导入状态和动作片段重新验证。
> 关联既有规则：`ANM-CORE-06`、`ANM-CORE-07`；ProjectACG 工具事实见 [动画压缩工具 Profile](../../Profiles/ProjectACG/CodexDaily/Development_Profile_2026-11-12.md)。

## 1. 适用场景

- 减少动画关键帧或曲线数据，同时要求尽可能保持动作结果。
- 评估恒定 `Scale` 曲线能否删除，或将恒值曲线从大量采样点简化。
- 估计曲线小数精度、FBX 导入压缩、重复资源和无用绑定分别影响什么成本。

## 2. 前提与依赖

- 区分独立可写 `.anim` 与 FBX 内嵌 clip；后者需要在副本上导出/编辑，避免把导入器控制的内容当作普通资源直接修改。
- 曲线包括绑定、时间范围、关键帧、切线、插值和 Wrap Mode。数值相同并不能单独证明中间曲线不变；加权切线可能出现微小求值差异。
- 删除整条恒值 `Scale` 曲线后，目标会使用模型/Prefab 的基准缩放，而不再由曲线明确赋值。`-1` 常用于镜像，不能按“常量”直接等同于无效。
- 文件文本大小、导入后内存、构建包体/Bundle 大小是不同指标；一项变小不能证明其他项同比下降。

## 3. 实现或排查步骤

1. 先盘点每个 Clip 的曲线类型、路径、键数、范围、恒值、Scale 轴和使用者；把武器挂点、根节点、镜像、循环、混合与事件一起纳入抽样。
2. 对完全恒值且确有多余关键帧的曲线，可生成候选副本并仅删除中间关键帧，保留绑定、首尾时间、值、平坦/阶梯语义和 Wrap Mode；跳过变化或可能超调的曲线。
3. 删除 Scale 曲线前验证基准 Transform 与 Animator 写入行为。恒为 `-1` 的镜像轴尤其需要保留/播放对比；若目标是不改变结果，优先保留曲线而只精简重复键。
4. 小数精度舍入会改键值或切线，是有损变更；先使用明确误差阈值生成副本，再检查最大位置/旋转/Scale 误差和敏感帧。不要将“仅三位小数”描述为无损。
5. 冗余中间关键帧只有在重建插值曲线后采样误差仍满足合同才可移除。抽样通过仍不覆盖骨骼接触、武器端点、混合树、表情和循环边界。
6. 分开报告 `.anim` 文件大小、导入内存估算、构建后 Bundle 大小和 Player 加载内存；重复依赖/重复打包排查属于包体路径，不要改动作曲线来代替资产依赖治理。

## 4. 风险与不适用边界

- 删除恒为 `-1` 的 Scale 可能移除镜像；删除恒为非 1 的缩放可能令动作回到基准姿态。
- 关键帧恒定不代表曲线可无损删掉；只保留两端的处理需要确认切线、阶梯插值、时间范围和加权曲线。
- 有误差阈值的减帧、切线舍入和数值舍入均可能改变动作；不能将测试容差写成位级等价。
- 采样误差通过不代表目标角色视觉、接触关系、Animator 混合和设备运行完全相同。
- 只删除某一模型层级中找不到节点的曲线有风险：同一 Clip 可能由其他 Prefab、Avatar 或运行时代码复用。

## 5. 验证与回退

先以候选副本测试恒值、正负 Scale、变化曲线、加权曲线、循环、保护节点和 Undo/Redo。对关键角色在相同帧播放并检查骨骼端点、武器挂点、脚底、镜像、表情与混合；分别复测曲线键数和四种大小口径。任何不接受的误差都恢复源 `.anim`/FBX 导入设置，或丢弃候选副本。
