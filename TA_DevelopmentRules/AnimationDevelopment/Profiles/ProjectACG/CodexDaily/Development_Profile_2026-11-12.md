# ProjectACG 动画压缩工具 Profile｜2026-11-12

> 类型：PROFILE；项目：ProjectACG；以下记录当日工具修改和会话测试状态。
> 关联参考：[动画曲线压缩与保真](../../../references/CodexDaily/Development_Reference_2026-11-12.md)；沿用 `ANM-CORE-06`、`ANM-CORE-07`。

## 1. 项目事实与现象

- 原 `AnimtionClipOptimizeToolKit` 的“降低曲线精度”会把浮点动画曲线的 Key 值与进/出切线舍入到小数点后三位。原“排除 Scale 曲线”会删除名称含 `scale` 的整条曲线，不判断是否恒为 1，也没有 Undo；恢复默认只重置窗口选项，不能恢复资产。
- 随后按用户约束改成：勾选“排除 Scale 曲线”时，只删除整条曲线始终恒为 `1` 或 `-1` 的 Transform Scale，各轴独立判断；变化曲线（如 `1 → -1`）保留。`weapon_l`、`weapon_r` 默认受保护，不区分大小写并默认保护子节点；保护名单可编辑。保护只影响 Scale 删除，不阻止精度舍入。
- 新增精度开关，默认开启、保留三位小数。取消“仅删除恒为 1 或 -1”后会删除未受保护节点的所有 Transform Scale，并提示风险；该模式不再由常值判断保护有变化的曲线。
- 新增“精简恒值曲线关键帧（保留曲线）”，默认开启：值完全一致且插值平坦或阶梯的曲线有超过两帧时只移除中间帧，保留曲线、绑定、首尾、时间范围和 Wrap Mode；变化或可能超调的曲线跳过。启用时恒值 Scale 优先被保留和精简；若要删除，需关闭该选项。
- 批量操作支持 `Ctrl+Z` / `Ctrl+Y`。目标为可写独立 `.anim`；FBX 内嵌动画需先导出。工具中文文本最终放在工具自己的常量文件中，打开工具时不依赖共享翻译表。

## 2. 根因、修正与证据

- **旧 Scale 选项范围过宽**：它删除整条属性曲线，可能移除动画缩放和固定非 1 缩放；后续缩窄为整曲线恒定 1 或 -1，并增加节点保护。
- **“不影响效果”目标与精度舍入冲突**：三位小数会改变值/切线，不属于严格无损。相比删除整曲线，优先新增保留曲线的恒值键精简。
- 会话报告 Unity 2022.3.62f3 隔离 EditMode 测试先后为 16/16、30/30、37/37、38/38 通过，最终 38 项含中文解析；`git diff --check` 通过。加权恒值曲线处理测得浮点求值差小于 `1e-6`，不是位级相同。

## 3. 项目约束与候选

- 目标用户要求尽量不改动作结果，因此“恒值曲线只减关键帧、保留曲线”是优先路径；删除 `-1` 仍可能改变镜像基准，必须显式接受并检查。
- 保护节点只影响删除动作，不保护它们免于三位精度舍入；实际工具的 UI 和 README 需保持该差异清楚。
- 是否有构建体积、运行内存或真实角色视觉收益，当日没有数据；不得把测试数通过等同于制作效果验收。
