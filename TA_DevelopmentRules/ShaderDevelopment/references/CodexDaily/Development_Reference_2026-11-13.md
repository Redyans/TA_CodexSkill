# Shader 屏幕坐标、循环混合与纹理分层参考｜2026-11-13

> 类型：REFERENCE；适用范围：带流动纹理、视角投射、程序闪点或多层合成的实时材质；使用前提：按目标项目 Shader、管线版本、相机、目标平台和材质重新验证。
> 关联既有规则：`DOC-03`、`CMP-01`、`ARC-01`、`ARC-02`、`VAL-03`；ProjectACG 当日实现边界见 [FlowMap 与星空 Shader Profile](../../Profiles/ProjectACG/CodexDaily/Development_Profile_2026-11-13.md)。

## 1. 适用场景

- FlowMap 循环时，纹理在周期回绕附近出现周期性的变淡与重新显现。
- 同一材质需要固定在模型上的绘制底色、持续平铺的动态细节、MatCap 或程序化视角效果。
- 评估模型 UV、Screen UV、视线方向投射或距离补偿，目标是稳定屏幕上的图案尺寸。
- Fresnel 遮罩、视角闪点、PBR 和透明效果共同参与合成，需要定位遮罩方向或 Alpha 过度衰减。

## 2. 前提与依赖

- 先明确要保持的量：模型表面上的纹理密度、屏幕像素宽度、贴图随视角变化的投射关系，三者不能在所有相机运动下同时固定。
- 确认 UV 通道、FlowMap RG 方向编码、颜色空间、Alpha 来源、Blend/ZWrite、PBR 输入和纹理采样器预算。
- 视角空间坐标依赖相机投影/屏幕尺寸；屏幕坐标效果还要评估物体或相机移动时的滑动感。
- 同一帧的贴图采样和材质开关数量可能扩大 Shader 变体与采样器占用；需要以目标设备核算。

## 3. 实现或排查步骤

### 3.1 先选坐标语义，再调平铺参数

| 目标 | 坐标选择 | 主要代价 |
| --- | --- | --- |
| 图案随模型表面固定，保留绘制布局 | 模型 UV | 远近变化时屏幕像素尺寸随投影变化。 |
| 图案固定屏幕尺寸，呈现“表面窗口” | Screen UV | 物体/相机移动时内容会滑过表面；屏幕宽高比需修正。 |
| 依观察方向改变投射内容 | View Direction 等视角投射 | 坐标还受模型法线和相机方向约束；不能等同于固定 Screen UV。 |
| 保留模型 UV 但减轻远处变密/变细 | 模型 UV 加视距补偿 | 需要参考距离和缩放范围；拉近拉远时图案会改变模型空间尺寸。 |

尺寸变化若只发生在远近，先比较视距补偿；若目标是图案保持屏幕像素尺寸，再选 Screen UV。Screen UV 的平铺需使用屏幕比例校正，建议用屏幕高度占比定义尺寸以避免不同宽高比下形状变形。对贴图本身非正方形的情况，还要把贴图宽高比纳入映射。

### 3.2 保持模型方向数据与投射坐标一致

1. 将纹理映射坐标与方向数据来源分开检查。模型 UV 中的 FlowMap RG 表示 UV 方向，不能未经转换直接当作屏幕水平/垂直方向。
2. 若动态层改用 Screen UV，明确 FlowMap 方向也需投射到相同坐标基底；模型旋转后检查流向是否符合预期。
3. 若法线也跟随屏幕投射，检查切线/视图基底转换。若只切换颜色纹理坐标，则保留法线贴图的既有模型空间契约。
4. 静态绘制底色、遮罩或速度区域若要跟随模型表面，应继续使用模型 UV；不要因动态细节采用屏幕坐标而一并改掉它们。

### 3.3 处理 FlowMap 周期显隐

1. 分辨身体整体透明度变化和内部流纹细节变淡。后者可能来自周期交接时两份错位纹理的平均，而非 Alpha 回跳。
2. 先降低单周期位移或流动强度，确认高位移造成的纹理错开是否为主要因素。
3. 可评估增加相位错开的采样层（例如双相改为三相），让纹理更平滑地交接；按周期位置计算各层权重，检查回绕处权重连续且总和稳定。
4. 对颜色阈值/遮罩检查平滑区间。狭窄阈值可能将变淡的细节压到不可见；循环噪声只能改变区域间的交接时间，不会恢复已经被平均掉的细节。
5. 比较默认模式与新模式的采样成本、细节柔化程度和最大强度边界；提供可关闭回退路径。

### 3.4 分开固定底色、流动细节和光照/高光

1. 将 UV 绘制的静态主色与平铺流动细节分为不同输入，明确先后组合关系（例如底色乘动态层）。
2. 对纹理 Alpha、材质颜色 Alpha、顶点 Alpha、遮罩逐项记录贡献，沿合成链只施加一次最终透明度，避免平方衰减。
3. 将自发光、Fresnel 或 MatCap 的混合位置定义清楚：哪些参与 PBR、哪些独立叠加/调制；Add 与 Mul 的零强度应为不改变原图的稳定端点。
4. PBR 通道打包必须由目標材質明示，不能把某工程通道映射迁作通用假设。

## 4. 风险与不适用边界

- Screen UV 可稳定屏幕尺寸，但物体运动时会出现滑动；固定模型空间图案和固定屏幕像素宽度是不同需求。
- 多相混合可减轻周期性交接的显隐，代价是增加采样并可能软化细节；不是消除任意高流速下的失真。
- 超过一张贴图的采样预算可能撞到平台采样器上限；复用 sampler 状态又可能限制过滤/Warp 组合，需量测并说明取舍。
- Fresnel 方向、透明队列、深度写入和 PBR 合成会改变最终观感；孤立像素测试不能替代角色/生产场景与移动端检查。
- 独立速度贴图、视距补偿参数或坐标模式若尚处方案阶段，应保留为候选，不写成当前已有能力。

## 5. 验证与回退

- 用固定相机、不同距离/视场角/正交尺度比较模型 UV、Screen UV 和视距补偿；记录屏幕尺寸、模型覆盖范围及内容滑动。
- 在周期起点、交接中点、周期回绕及反向播放检查颜色、透明度、流向与法线连续性。
- 用极端 Alpha/Mask、透明度为零、PBR 开关、MatCap Add/Mul 端点做像素与实渲回归；检查关闭新开关时与基线一致。
- 覆盖目标宽高比、目标图形 API、采样器上限及实际目标设备。明确哪些检查是编译、像素断言、隔离实渲或生产场景人工验收。
- 保留默认关闭的新模式和旧坐标/双相路径；出现变体、采样器或视觉回归时可逐项关闭并回到同场景基线。
